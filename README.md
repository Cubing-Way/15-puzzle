# 15 Puzzle

A sliding-puzzle simulator for sizes 3×3 up to 10×10, with a timer, undo/redo, solve statistics and step-by-step replays. It runs in the browser and as an Android app built with [Capacitor](https://capacitorjs.com/).

## Features

- **Play:** tap or click any tile in the empty square's row or column to slide it (and the tiles between) into the gap.
- **Scramble / Solve:** scrambles are made of random legal moves, so every puzzle is solvable; Solve jumps straight to the solved board.
- **Moves and timer:** the clock starts on your first move and can be paused or reset.
- **Undo/redo:** with the ← → buttons, Ctrl+Z, and Ctrl+Y or Ctrl+Shift+Z.
- **Options:** turn the move counter, the timer, or the highlight on tiles already in place on or off.
- **Solve history:** the sidebar shows today's average for each size you've solved today and your latest 8 solves. "Expand Solves" adds best single, average, standard deviation and solve count (today and all time), and lets you replay or delete any solve.
- **Look:** 19 board themes, 13 tile colors and a light/dark switch.
- **Saving:** the game in progress, your solves and your theme choices are kept in the browser's localStorage, so a reload picks up where you left off.

## Run it locally

The web app has no dependencies and no build step, but browsers won't load its JavaScript modules from a `file://` page, so serve the folder over HTTP:

```bash
git clone https://github.com/Cubing-Way/15-puzzle.git
cd 15-puzzle
npx serve .
```

Then open the address it prints. Any static server works, for example VS Code's Live Server or `python -m http.server`.

## Android app

Requires Node.js and Android Studio.

1. Install the Capacitor packages: `npm install`
2. Capacitor packages whatever is in `www/`, so replace its contents with the current `index.html`, `src/` and `styles/`.
3. Copy the web files into the Android project: `npx cap sync android`
4. Open it in Android Studio and run it from there: `npx cap open android`

## Project structure

```
index.html        Page layout; the JavaScript fills in most containers
src/
  main.js         Entry point: loads the saved game and wires everything together
  core/           Puzzle model: solved board, sliding tiles, win check, scrambler
  ui/             Tiles, moves/timer/undo panels, Scramble and Solve buttons, DOM helpers
  solves/         Solve history: sidebar, "All Solves" and replay windows, stats, time formatting
  storage/        localStorage access for the saved game and the solve list
  theme/          Board theme and color selects, light/dark switch
styles/
  desktop/        Layout for screens wider than 600px
  mobile/         Layout for screens up to 600px wide
  puzzle/         Board and tile themes (all screen sizes)
www/              Copy of the web app that Capacitor packages for Android
android/          Android project generated by Capacitor
```

Each `styles/*/index.css` imports its numbered files in cascade order, so later files override earlier ones.
